# Pantallas y flujos

## Mapa de pantallas
1. **Inicio:** CTA «Iniciar conversación»; accesos a Expresar, frases rápidas y ajustes. Comprar puede ser acceso contextual, no flujo duplicado.
2. **Conversación:** mensajes diferenciados por participante, teclado, control explícito del micrófono, voz sintetizada, «No entendí» y «Presentarme».
3. **Mostrar mensaje:** texto grande, alto contraste, posibilidad de orientar la pantalla y reproducir voz.
4. **Expresar:** entrada libre, texto original, sugerencias, aclaración de ambigüedades, aceptar/editar/rechazar y compartir.
5. **Confirmar información:** datos relevantes marcados, solicitud de confirmación escrita y comparación, sin asumir veracidad.
6. **Preferencias:** tamaño de fuente, idioma, voz, vibración, privacidad y frase de presentación.

## Flujo 1: conversación en gimnasio
Abrir app → iniciar conversación → opcionalmente presentarse → escribir pregunta → mostrar/reproducir → interlocutor habla o escribe → leer transcripción o mensaje → solicitar aclaración si es necesario → confirmar por escrito cuota e inscripción → finalizar y elegir descartar o guardar datos puntuales.

## Flujo 2: kiosco
Abrir conversación → preguntar precio → vendedor responde → leer importe transcrito → tocar «Confirmar» → solicitar que escriba el monto → comparar → ante discrepancia pedir aclaración → decidir compra. La app no certifica precios justos.

## Flujo 3: farmacia
Consultar producto y precio → transcribir respuesta → ante dosis o instrucciones sensibles solicitar confirmación escrita del profesional. No inventar instrucciones clínicas ni interpretar como consejo médico.

## Flujo 4: mensaje ambiguo
Escribir libremente → solicitar «Ayudame a expresarlo» → IA muestra interpretaciones alternativas si hay duda (pregunta vs afirmación, por ejemplo) → usuario elige o corrige → copiar/compartir. Nunca elegir silenciosamente por él.

## Flujo 5: «No entendí»
Durante conversación → tocar botón visible → elegir repetir / escribir / hablar despacio / explicar diferente → mostrar o reproducir solicitud → continuar sin perder contexto.

## Estados de interfaz
Permisos no concedidos, micrófono activo/inactivo, reconociendo voz, texto parcial, audio poco claro, error de red, IA no disponible, texto ambiguo, dato pendiente de confirmar, dato escrito por interlocutor, discrepancia y finalización.

## Primera apertura
Bienvenida breve; sin registro obligatorio; permisos contextuales solo cuando se necesiten.
